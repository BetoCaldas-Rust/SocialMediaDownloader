---
description: Gera uma mensagem de commit com 3 itens em inglês baseada nas mudanças recentes
---

Este workflow orienta a geração de mensagens de commit padronizadas para o projeto.

Siga estas instruções para gerar a mensagem:

1. Analise as mudanças realizadas nesta branch ou nas últimas interações.
2. Gere uma mensagem de commit em inglês seguindo o padrão Conventional Commits (ex: `feat:`, `fix:`, `refactor:`).
3. A mensagem deve conter obrigatoriamente 3 itens (bullet points) descrevendo as principais alterações.
4. Use uma linguagem clara, concisa e técnica.
